# Quill Lattice

Quill Lattice is an advanced spreadsheet platform inspired by Excel and modern spreadsheet tools, with AI-assisted workflows, API setup wizards, multilingual spellcheck dictionary support, and tools to open and attempt recovery of damaged workbook files. It is a companion to the Quill Word clone.

## Planned features

- **Excel-compatible spreadsheets**: XLSX support and a formula engine covering the familiar Excel function set.
- **Innovative features from other spreadsheets**: ideas drawn from modern spreadsheet tools, added alongside the Excel-style core.
- **AI capabilities**: AI-assisted formulas, data analysis and automation, with wizards that guide you through setting up AI API providers and keys.
- **Multilingual spellcheck**: wizards to download and use free spellcheck dictionaries for every language that has a useful free dictionary.
- **Corrupt file recovery**: tools to open and repair corrupt Excel files. This will incorporate the Immortal Unzipper plus code and recovery strategies from the author's other repositories.
