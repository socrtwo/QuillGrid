# The Utilities, Plus and Extras tabs

Anne's Grid 0.4 adds three tabs that bring the tool libraries of the popular spreadsheet add-ins into the program itself, plus a set of tools of its own. Every tool is an ordinary command: it can be put on the Quick Access Bar, on a custom tab, on a keyboard shortcut or into a macro, and it is found by Find and Run a Tool (Ctrl+Alt+F) or Search Commands (Alt+Q). Each tool accepts its settings as a macro argument, so a recorded macro replays it without the dialog.

All of the tools are original implementations written for Anne's Grid from the public descriptions of what the add-ins do. No code, text, icons or screenshots of any add-in were used. The add-in names below are given to say where an idea comes from (nominative use); Anne's Grid is not affiliated with or endorsed by their publishers. See [LEGAL.md](LEGAL.md).

| Group | What is in it |
|---|---|

| Publishing | Title Case by style-guide rules, smart and straight quotes and dashes, fraction characters, thin spaces as thousands separators, spacing around punctuation, reading ease score, check and convert ISBNs (10 ⇄ 13), URL slugs, points ⇄ picas/millimeters/inches/pixels |

## For macro authors

Every tool with a dialog takes an object argument with the dialog's settings, so a macro step such as `util.shiftDates` with `{ "n": 1, "unit": "months" }` runs without asking. Developer ▸ Copy Command ID List gives the ids; `docs/COMMANDS.md` lists every command with its tab and group.
